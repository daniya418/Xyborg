# Xyborg - Professional Audio Studio Portfolio

A high-end, cinematic portfolio website for Xyborg music studio.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## 📦 Deployment

This project is optimized for Vercel deployment. Simply connect your repository to Vercel and deploy.

## 🎨 Features

- Dark, cinematic design with blood red accents
- Custom audio players
- Smooth scroll animations with Framer Motion
- Fully responsive design
- SEO optimized
- Fast loading with lazy-loaded media

## 📝 Adding New Portfolio Items

To add new portfolio items, edit `src/data/portfolio.ts` and add your project data following the existing structure.

## 🛠️ Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite
